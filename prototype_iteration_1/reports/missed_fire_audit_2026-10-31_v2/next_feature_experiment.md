# Next feature experiment: registration draft

Status: **design registered; features and new models have not been built or trained**. This is the next modelling task after the missed-case audit, not a claim of completed model improvement.

1. Create a new target version that excludes explicitly identified prescribed burns. Preserve unknown cause/type provenance and retain otherwise eligible events; do not infer human cause means prescribed. Reconcile event counts and cell-day labels, document agency-specific codes, and recompute all target-derived history consistently. Keep the legacy target and final artifacts unchanged.
2. Keep the 10 km row universe and strict pre-target-day observation cutoff. Add only existing, timely CWFIS history: trailing 3- and 7-day FWI/DMC means, changes from t-3/t-7 to t-1, coverage counts and incomplete-window flags. Missing days stay missing. Do not substitute current fuel/forest maps into historical years.
3. Fit any imputation, transformations, model choice and calibration only on the permitted training/calibration partitions. Use the existing forward 2014/2015 selection folds, 2016 calibration and exposed 2017 diagnostic check, with existing geographic blocks and buffers. These are development checks, not a new final evaluation.
4. Compare three fixed specifications on the SAME new target: reference inputs; reference plus weather history; history with deeper missingness/coverage indicators. Keep the reference LightGBM hyperparameters and negative-sampling policy fixed for this first feature ablation. Fit a matching reference on the new target so a target change is not mistaken for a feature gain.
5. Retain the 1% daily capacity and deterministic tie rule. Require higher mean development AP, no lower mean capacity recall, and no fold AP below 90% of the matching reference. Report Brier score, log loss and calibration plots; reject promotion if either probability loss worsens. Report paired date-block uncertainty and per-month/geography support. Development acceptance only authorizes further evaluation, not automatic live deployment.
6. Register an untouched, source-consistent later season/year or genuinely reserved geography before accessing its labels for scoring. Record source vintages, target-policy hashes and exclusion boundaries first. The old 2017, 2019 and 2025 results are exposed and cannot become a new clean test. If no new eligible data are available, report development evidence only.
7. Operational promotion separately needs forecast-time input availability, qualified live weather/FWI handling, monitoring and appropriate forecast evaluation. Spread remains a separate reconstruction experiment until initial states and time-matched progression support forecast validation.

Do not change this specification after seeing its results without recording a new version. Dataset acquisition and implementation remain future work. No new provider account, paid service or frontend is needed to start the development ablation using existing archives.
